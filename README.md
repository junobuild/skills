# Juno Agent Skills

Agent skills for [Juno](https://juno.build) — an open-source SDK and serverless platform for building full-stack web apps.

## Install

```bash
npx skills add junobuild/skills
```

## Skills

### `juno`

Covers everything you need to build with Juno:

- CLI commands and `juno.config` structure
- Datastore, Storage, and Authentication SDK (`@junobuild/core`)
- Serverless functions in TypeScript and Rust
- Local development with the emulator
- GitHub Actions CI/CD and access keys

## Contributing

Skills are plain Markdown files. If something is outdated or missing, PRs are welcome.
